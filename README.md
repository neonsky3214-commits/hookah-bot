# LIWAN Bot

Telegram-бот кальянной LIWAN: брони столов через Mini App, события, меню,
галерея, лояльность (Loona), напоминания, оценки, рассылка, статистика.

## Интеграция с iiko (брони → iikoFront)

Бронь, созданная гостем в боте, автоматически создаёт резерв в iiko —
хостес видит его на кассе в штатном экране резервов. Если резерв создать
не удалось (касса офлайн, стол не привязан), бронь в боте всё равно
сохраняется, а админ-чат получает сообщение «внесите резерв вручную».

### Требования на стороне iiko

- модуль **«Банкеты и резервы»** (iikoTableService) — без него API резервов не работает;
- **apiLogin** для iikoCloud API (выдаёт iiko или дилер);
- схема залов и столов заведена в iikoOffice;
- касса (терминал) онлайн в момент создания брони.

### Переменные окружения

| Переменная | Обязательная | Значение |
|---|---|---|
| `BOT_TOKEN` | да | токен бота |
| `ADMIN_CHAT_ID` | да | чат для уведомлений о бронях |
| `ADMIN_IDS` | да | ID админов через запятую |
| `WEBAPP_URL` | да | URL Mini App |
| `DATABASE_URL` | да | PostgreSQL |
| `IIKO_API_LOGIN` | нет | apiLogin iikoCloud; не задан — интеграция выключена |
| `IIKO_ORGANIZATION_ID` | нет | ID организации; по умолчанию первая доступная |
| `IIKO_TERMINAL_GROUP_ID` | нет | ID терминальной группы; по умолчанию первая |
| `IIKO_RESERVE_DURATION_MIN` | нет | длительность резерва, по умолчанию 120 |
| `LOONA_CLIENT_ID` / `LOONA_CLIENT_SECRET` / `LOONA_TEMPLATE_ID` | нет | лояльность Loona |

### Первичная настройка (один раз, в чате с ботом от имени админа)

1. `/iiko` — проверить подключение: токен, организация, терминальная группа.
2. `/iiko_tables` — получить список залов и столов iiko с их ID.
3. `/iiko_map LIWAN 3 <id>` — привязать стол №3 зоны «LIWAN» к столу iiko.
   Повторить для всех столов обеих зон (`LIWAN` 1–12, `Веранда Liwan` 1–6).
   `/iiko_map` без аргументов — текущие привязки, `/iiko_map del <зона> <стол>` — удалить.

### Ограничения

- Отмена и перенос резерва через iikoCloud API недоступны — при отмене или
  переносе брони бот присылает админу напоминание снять/перенести резерв на кассе.
- Занятость столов в Mini App — объединение броней бота и резервов iiko
  (`restaurant_sections_workload`, кеш 60 сек): резервы, внесённые хостес
  на кассе, тоже подсвечиваются занятыми.
